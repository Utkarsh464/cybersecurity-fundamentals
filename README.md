# Cybersecurity Fundamentals

Personal learning notes from the **IBM SkillsBuild Cybersecurity Fundamentals** learning plan, written course by course.

All four courses in the plan are **100% complete**. This repository documents the full credential path — from foundational concepts through offense and defense to the job landscape — with each course's module notes researched through primary sources (IBM, CISA, NIST, MITRE, OWASP, Lockheed Martin, Europol and others).

This is a learning log, not a textbook. If a section feels light, it is because the course itself covered it lightly, and I kept the scope to what the course actually taught.

## Credential Path

The **IBM Cybersecurity Fundamentals** credential (via Credly) requires completing all four courses and passing each final assessment. All four are done — the credential is earned on the IBM/SkillsBuild side, and this repo is the documented evidence trail.
